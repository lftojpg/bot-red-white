# 🔴⚪ Bot Red-White (Versión Completa)

Bot de WhatsApp desarrollado en **Node.js** utilizando la librería `@whiskeysockets/baileys`, con soporte para vinculación por número telefónico, sistema de registro simulado, control de accesos VIP y créditos limitados.

## 🚀 Características
* **Vinculación por número:** Conéctate fácilmente ingresando tu número sin necesidad de códigos QR.
* **Sistema de Registro (`.register`):** Simula el registro de usuarios otorgando un acceso VIP temporal y un bono de créditos.
* **Sistema de Créditos:** Restringe comandos avanzados si no cuentas con créditos o si no eres VIP.
* **Comandos de Consulta Simulada:** 
  * `.dni [número]` -> Simula búsqueda de titular por documento de identidad.
  * `.num [número]` -> Simula consulta de línea y titular por número telefónico.
